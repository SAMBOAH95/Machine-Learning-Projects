# Student Score Prediction

## Overview
This project uses Linear Regression to explore the relationship between students' study hours and examination scores.

## Objective
To predict examination scores based on students' study hours.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Methodology
1. Data inspection and preparation
2. Exploratory data analysis and visualisation
3. Train-test splitting
4. Linear Regression model training
5. Model evaluation

## Results
- MAE: 2.448
- RMSE: 3.295
- R²: 0.232

The model identifies a positive relationship between study hours and examination scores. Study hours alone explain approximately 23.2% of the variation in test scores.

## Dataset
Student Performance Factors — [Kaggle](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors)
